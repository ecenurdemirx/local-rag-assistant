# Generative AI Basics

Source basis:
IBM - What is Generative AI?
https://www.ibm.com/think/topics/generative-ai

Generative AI is a type of artificial intelligence that can create new content.

Depending on the model, generative AI can produce:

- text
- images
- audio
- video
- software code

A user usually gives the system a prompt. The model then generates a response based on patterns learned during training.

## Foundation models

Many generative AI applications are built on foundation models.

A foundation model is trained on a large amount of data and can later be used for many different tasks.

Large language models, often called LLMs, are foundation models designed to work with language. They can answer questions, summarize text, translate languages, generate code, and perform other language-related tasks.

## How generative AI learns

During training, a model learns patterns and relationships in data.

For a language model, this includes relationships between words, phrases, concepts, and longer pieces of text.

The model does not simply store a perfect copy of every training example. Instead, it learns statistical patterns that help it produce new outputs.

## Prompts

A prompt is the instruction or input given to a generative AI system.

A clearer prompt often gives the model a better understanding of the user's goal.

For example, instead of asking:

"Explain computers."

a user could ask:

"Explain how a computer CPU works in simple language for a beginner."

## Limitations

Generative AI can produce incorrect or invented information. This is sometimes called hallucination.

Outputs should therefore be checked when accuracy is important.

Generative AI can also raise issues involving privacy, bias, copyright, safety, and misuse.

The technology is useful, but it should be used with an understanding of both its capabilities and its limitations.
